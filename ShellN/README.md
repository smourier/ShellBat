# ShellN

AOT compatible, low level .NET bindings for the Windows Shell, built on DirectN.

ShellN is the generated interop layer. It exposes the COM interfaces, item id lists (PIDLs) and the related Win32 surface, ready for trimming and Native AOT. The friendly, object oriented API lives in the companion package ShellN.Extensions.

Available as a Nuget package here: https://www.nuget.org/packages/ShellN
